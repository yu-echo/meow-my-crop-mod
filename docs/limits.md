# 限制与风险

## 做不到的

- **发现不了表外的新兑换码**。客户端只认游戏资源里的 `TbCouponCode` 表，公告里发了但没进表的码，
  客户端自己就判无效，插件也没有办法。游戏更新、表里多了新码之后，重启游戏就会被插件捡到。
- **联机时远端作物不走 `Grow`**。生长加速只作用于你自己的地块（远端走快照同步）。
- **自动开罐 / 自动合成**需要先在游戏里打开过一次对应页面（猫罐头页、合成页），
  插件才拿得到池配置。

## 会动到服务端的

- **按键倍率会写进 Steam 统计**（`total_key_clicks`），这是改服务端数字，
  理论上存在被判定异常的可能。担心就切回 ×1，之前的数字不会回退。
- **开罐走的是 Steam 物品兑换**（`SteamItemExchange.ExchangeAsync`），
  代币和产出都由 Steam 侧结算，插件的「开罐免果实」只影响本地果实。

## 活动相关

- 活动罐头的兑换逻辑**本身不校验活动时间**（`PerformExchange` 只看配置 + 果实 + Steam 服务），
  但界面上活动卡片在非活动期会被隐藏，`ActivityHelper.GetActivityCannedId()` 在没有活动时返回 2
  （普通罐头）。所以正常点不到，也不建议绕过。

## 已知未验证

- 自动偷菜没有在真实联机房间里跑过完整流程。
- 生长加速在多人房间里的表现未测（按代码推测只影响本地作物）。

## 兼容性

- 只针对当前版本（Unity 2022.3.62f3 / Steam AppID 4201710）编译。
  游戏大更新后 `Plant.Grow`、`SteamStatsManager.HandleMessage` 这类方法签名若变动，补丁会失效，
  日志里会出现「补丁 XXX 失败」。
